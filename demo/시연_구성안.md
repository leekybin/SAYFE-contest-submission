# SAYFE 사고 대응 시연 · 80초

이 자료는 앱 구현이 아닌 공모전 콘셉트 영상 제작용입니다.
Android 앱은 기존 Vehicle 2.3.2 / NaviHelper 3.0.5 테스트 화면으로 복원했습니다.

## 제작물
- SAYFE_pleos_demo.mp4: 실제 에뮬레이터 주행·감속·정차와 두 차량 접촉 재현을 나란히 구성한 영상
- pleos-driving-raw.mp4: 27초 실제 에뮬레이터 촬영 원본 (0→45km/h→0, D→P)
- 실제 촬영에는 충돌·비상등을 발생시키지 않았습니다. 접촉 및 비상등은 애니메이션으로만 연출합니다.
- 현재 홈페이지와 두 영상은 민트색 내 차량과 주황색 상대 차량의 측면 접촉 시나리오로 통일했습니다.
- Pleos 합성본 재생성: node demo/compose-pleos.cjs (기존 촬영 원본 사용)
- SAYFE_concept_demo.mp4: 제출·재생용 H.264 영상
- SAYFE_concept_demo.webm: 브라우저 녹화 원본
- preview-*.png: 장면별 미리보기
- 재생성: npm.cmd install --prefix demo/render-tools --no-save --package-lock=false playwright @ffmpeg-installer/win32-x64
- 프로젝트 루트에서 node demo/render-demo.cjs 실행 후 node demo/export-mp4.cjs 실행
- sayfe-demo.html: 외부 라이브러리 없이 실행하는 1920×1080 자막형 애니메이션
- 브라우저에서 재생 / 일시정지 / 구간 이동 가능
- ‘영상 만들기 · WebM’: 처음부터 80초 재생 후 WebM 다운로드
- 녹화 중에는 탭을 전면에 유지합니다. 실제 녹화 파일 생성 여부와 다운로드 완료를 확인합니다.
- 음성 없음. 음성 SDK 및 AI 기능은 예시 화면임을 표시합니다.
- 사진·인물·차량번호·개인정보는 사용하지 않습니다.

## 타임라인
| 시간 | 장면 | 자막 및 처리 절차 |
|---|---|---|
| 00–11초 | 직선 도로 주행 | 주행 중에는 운전에 집중 |
| 11–18초 | 오른쪽 상대 차량의 차선 진입, 내 차량 측면과 접촉, 감속 | 두 차량 및 접촉 지점을 명확하게 표시. 실제 충돌 물리나 사고 감지 아님 |
| 18–26초 | 안전한 정차 장면으로 전환 | 속도 0, 기어 P, 비상등 상태 표시. 정차 위치까지의 이동 과정은 생략 |
| 26–36초 | 안전 확인 화면 | 부상·화재·2차 사고 위험 확인. 위험하거나 불확실하면 긴급 도움 요청을 우선 |
| 36–48초 | 현장 소통 예시 | 상대방 발화를 문자로 확인하고 선택한 답변을 전달하는 콘셉트 |
| 48–60초 | 사고 자료 정리 예시 | 안전 확보 후 사진, 사고 시각, 사용자 확인 위치, 당사자별 진술을 구분 |
| 60–73초 | 검토 및 인계 예시 | 미확인 항목과 질문을 남기고 공유 대상·자료를 사용자 승인 후 인계 |
| 73–80초 | 핵심 가치 | 사고 이후에도 혼자 막막하지 않도록, SAYFE |

## Pleos 실제 화면 촬영 경로
1. Pleos Connect v2.1.0 에뮬레이터 실행.
2. Android Studio 터미널에서 adb -s emulator-5554 forward tcp:8088 tcp:8088 실행.
3. PC 브라우저에서 http://127.0.0.1:8088/ 접속.
4. P 상태에서 Theme: Highway 선택. First person 또는 Third person 선택.
5. D 선택 후 ACCEL / BRAKE와 조향으로 주행·감속 장면 촬영.
6. 완전히 정지한 뒤 P 상태로 전환.
7. Emulation Controls → Convenience → Hazard Lights에서 비상등 상태 연출.
8. 필요하면 Door Position 변경 후 원래 SDK 앱의 ‘4개 도어 상태 새로고침’으로 실제 값 반영 촬영.

공식 문서에서 차량 충돌·손상 물리 엔진 또는 자동 사고 감지 기능은 확인하지 못했습니다.
실제 Virtual Console 장면을 쓰는 경우 주행·정차 장면을 촬영하고, 사고 순간은 별도 연출 컷으로 연결합니다.
독립 HTML 영상은 Pleos 콘솔 실녹화라고 소개하지 않습니다.
자동 감지·STT·AI·보험사 접수는 구현된 실제 결과로 표시하지 않습니다.

## 사고 처리 장면 작성 원칙
- 자료 수집보다 인명 안전과 긴급 도움 요청을 우선합니다.
- 영상에서는 안전이 확보된 뒤 기록하는 경미한 접촉사고로 설정합니다.
- 진술은 운전자와 상대방을 구분하며, AI가 사실이나 과실을 확정하지 않습니다.
- 위치와 사진은 사용자 확인 전까지 미확인으로 표시합니다.
- 긴급 신고·보험 접수·외부 전송이 실제 수행된 것으로 표현하지 않습니다.
- 추가 요청을 기록하고 담당자에게 확인할 질문으로 남깁니다.
- 고속도로 실제 사고 행동 지침이나 법률 안내를 대신하는 자료가 아닙니다.
